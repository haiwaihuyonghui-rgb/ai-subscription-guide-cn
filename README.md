## 先看三件事：地区、条款、价格

1. **地区。** OpenAI 帮助中心的《ChatGPT 支持的国家和地区》写明，从未列出的地区访问或提供访问，账号可能被封或暂停；中国大陆不在列表中。Anthropic 的《支持的国家和地区》页面写明"未列出的国家和地区不受支持"，中国大陆、香港、澳门都不在列表中（2026-10-20 查看）。这是走任何一条路线都绕不开的前提。
2. **条款。** OpenAI 使用条款不允许把账号凭证分享给别人或让别人使用你的账号；Anthropic 的用量按账号计算。所以"合租""拼车""成品号"从条款上就站不住，本指南不介绍。
3. **价格。** 下文只写各家官方的美元标价并注明来源，不写任何人民币售价。代充、礼品卡等第三方渠道的人民币价格差别很大，和"官方价"没有固定换算关系。

## 国内开通的几条路线

| 路线 | 需要什么 | 优点 | 缺点与风险 | 适合谁 |
|---|---|---|---|---|
| 自己用海外卡在官网订阅 | 支持地区发行的信用卡或借记卡 | 钱直接付给官方，订阅完全在自己手里，可自动续费 | 国内发的卡（包括不少 Visa、万事达）常被拒；办海外卡门槛高 | 有海外账户、长期使用 |
| 虚拟信用卡 | 在虚拟卡平台开卡、充值 | 按官方价付款 | 开卡费、手续费、汇率差叠加；拒付率高；平台有停服风险（野卡 2025-07-12 停服，后以 WildAI 恢复但不再提供卡号，见公开报道） | 不建议作为长期方案 |
| 外区 Apple ID + 礼品卡（App 内订阅） | 外区 Apple ID、同地区礼品卡、iPhone | 不用信用卡，订阅走苹果 | 步骤多；Apple ID 地区和礼品卡必须一致；余额不足续不上；取消只能在手机订阅设置里；App 内价格由应用商店定 | 只用手机、不想研究卡 |
| 代充（订阅代付） | 你的账号邮箱；自助开通另需一段登录信息；不需要密码 | 不用自己的卡，会员开在自己账号上 | 要挑卖家；不自动续费，到期自己再买；付款记录不在你名下，不能向官方申请退款 | 电脑用得多、想省事 |
| 合租 / 成品号 | — | 单价最低 | 违反使用条款；账号不是你的；聊天记录互相可见；额度被分；容易被限制 | 不建议 |

各产品的小差别：

- **ChatGPT**：五条路线都有人走；Plus 和 Pro 的 App 内订阅价格由应用商店决定，和网页版可能不同。
- **Claude**：Pro 包含 Claude Code；Max 两档只能月付；iOS App 内也可订阅。年付 Pro 要一次交一年，拿不准是否长期用的先按月。
- **Gemini（Google AI Pro / Ultra）**：通过 Google One 订阅，需要一个付款方式所在地区可用的 Google 账号；官方页面按地区显示本地货币。
- **Grok（SuperGrok）**：在 grok.com 或 X 应用内订阅；X Premium 系列也带 Grok 权益，两套订阅不要重复买。

## 怎么判断代充靠不靠谱

代充本身只是"由卖家替你付款"，风险全在卖家的做法上。下单前对照这 8 条：

1. **开在你自己的账号上。** 发你一个现成账号的是成品号，不是代充。
2. **不要你的密码、手机验证码。** 自助开通如果需要一段登录信息，只填在开通页面，不发到群里；开通后在设置里"退出所有设备"，它就失效了。
3. **价格别低于官方标价的一半。** 几十块一个月的，多数是退款单、盗刷卡或礼品卡套利，付款被撤销后订阅会被收回。
4. **掉会员怎么处理要白纸黑字。** 质保期多长、怎么补、要不要订单号，写清楚才算数，一句"有质保"不算。
5. **开通失败怎么办。** 卡密或款项是否退回、能不能重新提交。
6. **出问题能找到真人。** 只有一个网页、没有任何联系方式的，谨慎。
7. **有条款和主体。** 售后规则、退款规则、经营者是谁，页面上找得到。
8. **第一次先买一个月。** 用顺手再买长期。

五种红旗：让你关二次验证；让你装软件或插件；拉群合租；临时加收"手续费"；中途让你换一个账号登录。

付款后的自检：刷新页面，用你平时的账号看到会员标识、聊天记录都在；到设置里退出所有设备再重新登录；保存订单号和开通截图。

## 常见问题 FAQ

1. **代充会封号吗？** 封号看的是钱从哪来和账号怎么用：付款被撤销、多人共用、频繁切换地区、违规内容。开在自己账号、正常渠道付款的代充，和自己绑卡的风险来源是一样的。
2. **代充要给卖家什么？** 账号邮箱；自助开通另需一段登录信息。不需要密码、验证码、银行卡。要密码的不要用。
3. **怎么确认开在我自己的账号上？** 刷新后用你平时的账号看到会员标识，聊天记录都在；然后在设置里退出所有设备再登录。
4. **代充的会员能向 OpenAI / Anthropic 申请退款吗？** 不能，付款记录不在你名下，只能按卖家的售后规则处理，所以下单前先看条款。
5. **代充的会员会自动续费吗？** 不会，因为没有绑你的卡。到期前自己再买一次。
6. **中国大陆能用 ChatGPT / Claude 吗？** 两家的支持地区列表都不含中国大陆；官方写明从不支持的地区访问可能导致账号被限制。使用时网络要稳定在一个支持的地区，不要来回切换。
7. **Claude Code 要单独买吗？** 不用。它包含在 Claude Pro / Max 里，也可以用 Console（API 按量）账号登录。见 [docs/claude.md](docs/claude.md)。
8. **Plus 和 Pro、Pro 和 Max 怎么选？** 先买低一档用一个月，一周里好几天撞额度再升。同一账号升级，记录都在。
9. **要不要选年付？** 便宜但要一次交一年，中途退费以官方规则为准；拿不准就按月。
10. **为什么本仓库不写人民币价格、不放购买链接？** 第三方渠道价格变动快、差别大，写了反而误导；本仓库定位是导读，购买决定请在看完路线和条款后自己做。
